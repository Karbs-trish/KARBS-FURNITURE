# KARBS Furniture 

A modern, responsive static website for **KARBS Furniture**, designed to showcase furniture collections and provide customers with an elegant browsing experience.

---

##  Features
- Responsive design (works on desktop, tablet, and mobile)
- Clean layout with **HTML, CSS, and JavaScript**
- Easy navigation for product categories
- Lightweight and fast-loading static site
- Deployable on **Vercel** for seamless hosting

---

##  Project Structure
├── index.html        # Main entry point
├── furniture.css     # Stylesheet
├── furniture.js      # JavaScript functionality
